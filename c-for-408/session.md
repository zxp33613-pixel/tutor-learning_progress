## TL;DR

- 408 只认 `int main(void)` + `#include <stdio.h>` 的标准骨架。

## c1 · 程序骨架与 I/O

### 1. 最小可用骨架

```c
#include <stdio.h>

int main(void) {
    int a = 1;
    printf("%d\n", a);
    return 0;
}
```

编译链四步：`预处理 → 编译 → 汇编 → 链接`，产物 `.i → .s → .o → 可执行文件`。

### 2. printf 格式符

真实输出（`int a = -1;`）：

```
%d=-1  %u=4294967295  %x=ffffffff  %o=37777777777
%c=A  %d=65  ch+1=B
%.2f=3.14  %8.3f=   3.142
sizeof: int=4 char=1 double=8
```

| 格式符 | 用途 | 记忆点 |
|---|---|---|
| `%d` / `%i` | 有符号十进制 | 最常用 |
| `%u` | 无符号十进制 | 同一个 `-1` 变成 4294967295 = `2^32-1` |
| `%x` / `%o` | 十六进制 / 八进制 | 看位模式：`ffffffff` |
| `%c` | 字符 | `%c` 输出 'A'，`%d` 输出 65 |
| `%s` | 字符串 | 遇 `'\0'` 停 |
| `%f` | 浮点 | 默认 6 位小数；`%.2f` 保留 2 位 |
| `%5.2f` / `%8.3f` | 宽度.精度 | 右对齐补空格 |
| `%zu` | `sizeof` 的结果 | 别用 `%d` 打 `sizeof` |
| `%p` | 指针 | 打印地址 |
| `%%` | 输出一个 `%` | — |

408 最爱考：同一变量用 `%d` / `%u` 输出值不同。

### 3. scanf 的两个坑

```c
int n; char c;
scanf("%d", &n);      // ① 必须取地址 &
scanf(" %c", &c);     // ② %c 前加空格，跳过换行
```

- `%d` 自动跳过前导空白；`%c` 不会。
- 返回值 = 成功读入的项数；读到结尾返回 `EOF`。

### 4. 作用域与生命周期

| 定义位置 | 作用域 | 生命周期 | 初值 |
|---|---|---|---|
| 函数内 `int x;` | 本函数 | 每次调用重建 | 未定义（垃圾值） |
| 函数内 `static int x;` | 本函数 | 整个程序，只初始化一次 | 0 |
| 全局 `int x;` | 本文件及 `extern` 可见 | 整个程序 | 0 |
| 全局 `static int x;` | 仅本文件 | 整个程序 | 0 |

```c
int counter(void) { static int c = 0; c++; return c; }
printf("%d %d %d\n", counter(), counter(), counter());
// gcc 实际输出：3 2 1  ← 实参求值顺序未定义，别记具体值
```

### 5. 类型大小与整型提升

```
sizeof: int=4 char=1 double=8   （short=2, long=8）
```

`char` 参与算术提升为 `int`：`'A' + 1 == 66`，`printf("%c", ch+1)` → `B`。

## Key Examples

```c
#include <stdio.h>
static int calls = 0;
int counter(void) { static int c = 0; c++; calls++; return c; }

int main(void) {
    int a = -1;
    printf("%d %u %x\n", a, a, a);      // -1 4294967295 ffffffff
    char ch = 'A';
    printf("%c %d %c\n", ch, ch, ch+1); // A 65 B
    double f = 3.14159;
    printf("%.2f %8.3f\n", f, f);       // 3.14    3.142
    return 0;
}
```

## Gotchas

- `%u` 打印负数 → 得到 `2^32 + n`，不是"绝对值"。
- `scanf("%d", n)` 漏 `&` → 崩溃或垃圾值。
- `%c` 前不加空格会读到上一行的换行符。
- 多个带副作用的函数调用放在同一 `printf` 参数里 → 求值顺序未定义，408 只问"不确定"。
- 局部 `int x;` 未初始化是垃圾值，全局/static 才默认 0。

# c2 整型表示与位运算（课堂讲解）

## Answer

补码 = 取反加一；32 位下 `-1` 是 `0xFFFFFFFF`。
无符号运算按模 2^n 回绕：`(unsigned char)255 + 1 == 0`。
有符号溢出是未定义行为，实践中回绕：`(signed char)127 + 1 == -128`。
左移可能溢出；无符号右移补 0，有符号负数右移实现定义（通常算术右移）。

## Key Examples

```c
printf("%x %u\n", -1, (unsigned)-1);        /* ffffffff 4294967295 */
printf("%d %d\n", 5 >> 1, -5 >> 1);         /* 2 -3 */
unsigned char x = 250; x += 10;             /* 260 mod 256 = 4 */
```

位技巧：取第 k 位 `(x>>k)&1`；置 1 `x|=1<<k`；清 0 `x&=~(1<<k)`；翻转 `x^=1<<k`。

## Gotchas

- 位运算优先级低于比较：`x & 1 == 0` 是 `x & (1==0)`。
- `unsigned` 减到 0 再减会回绕成巨大正数（死循环陷阱）。
- `printf("%d", x)` 打无符号变量要用 `%u`，否则可能打印负数。

## Check（待作答）

```c
unsigned char x = 250; x = x + 10; printf("%u", x);
```

正确答案：**B. 4**（模 256 回绕）。
