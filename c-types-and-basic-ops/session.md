# C 语言：类型与基本运算

> Taught: 2026-11-18（续至 2026-11-20）

## TL;DR

- 类型决定：位模式如何解释、以及通常占多少字节；名字只是标签。
- 整数 `/` 是整除；要小数须在运算前出现浮点操作数（常写 `(double)a / b`）。
- `i++` 取旧值、`++i` 取新值；强制转换不改原变量；signed/unsigned 混用要小心。

## Explanation

### c1 变量与类型直觉

在 C 里，数据是：**有名字的内存 + 类型（解释规则）**。

```c
int n;        /* 声明 */
n = 42;       /* 赋值 */
int m = 7;    /* 声明并初始化 */
```

`sizeof` 向编译器询问类型或变量的字节数；常见桌面上 `sizeof(int)` 常为 4，但标准不保证，可移植代码应使用 `sizeof`。

未初始化本地变量：盒子存在，内容可能是垃圾。只有**读取**它才构成未定义行为；先写入再读则安全。

```c
int a;           /* 未初始化 */
int b = 10;
a = b + 1;       /* 只写 a，读的是 b → 相对安全 */

int x;
int y = x + 1;   /* 读了未初始化的 x → 危险 */
```

### c2 整型家族

三根轴：宽度（`short`/`int`/`long`/`long long`）、符号（`signed`/`unsigned`）、字面量后缀。

- 非负计数（人数、长度、下标）可倾向 `unsigned` / `size_t`，但避免与有符号随意混比。
- `unsigned` 是类型修饰；`1u` 的 `u` 是字面量后缀。
- `unsigned int x = -1;` 通常得到该宽度下很大的非负值（模 2ⁿ），不是打印意义上的 -1。
- 前导 `0` 的字面量是八进制（`014 == 12`）。

### c3 浮点与 char

- `float` / `double`：近似实数；默认小数常量多为 `double`；`0.1f` 才是 `float`。
- 浮点不宜用 `==` 判断“数学上是否相等”。
- `char` 本质是小整数；`'A'` 在 ASCII 下常为 65；`'A'` ≠ `"A"`（后者是字符串）。
- `char` 是否带符号因平台而异；原始字节更常用 `unsigned char`。

### c4 算术运算

- `+ - * / %`；两边都是整数时 `/` 为整除（向 0 截断）。
- `double x = 7 / 2;` 得到 `3.0`（先整除再转换）；要小数需 `7 / 2.0` 或 `7.0 / 2`。
- `%` 只用于整数；正数时 `(a/b)*b + (a%b) == a`。

### c5 赋值与自增

- `=` 是赋值（表达式值即所赋之值）；相等比较是 `==`。
- `+= -= *= /= %=` 为复合赋值。
- `++i`：先加，表达式为新值；`i++`：表达式为旧值，再加。
- 同一表达式内对同一变量多次修改属于未定义行为，不要写。

### c6 隐式提升与强制转换

- 不同类类型运算时，编译器常做隐式转换；也可用 `(type)expr` 强制转换（不修改原变量）。
- `double r = a / b;`（`a,b` 为 int）仍是整除；`double r = (double)(a / b);` 也太晚——括号里已经整除完了。
- 正确时机：`double r = (double)a / b;`（或 `a / (double)b`）。
- 变窄赋值（`double→int`、大整数→`char`）可能截断；signed 与 unsigned 比较可能反直觉。

## Key Examples

```c
#include <stdio.h>

int main(void) {
    int n = 1;
    printf("%zu\n", sizeof(int));
    printf("%zu\n", sizeof n);
    return 0;
}
```

```c
int s = -1;
unsigned int u = 1u;
unsigned int x = -1;   /* 很大的非负值，不是“负一” */
```

```c
float  f = 0.1f;
double d = 0.1;
char   c = 'A';   /* 小整数，常为 65 */
/* 'A' 是字符；"A" 是字符串——不是同一种东西 */
```

```c
int a = 7, b = 2;
double y = (double)a / b;     /* 3.5 */
double wrong = (double)(a / b); /* 3.0：转换太晚 */
```

## Gotchas

- 类型不管变量叫什么，管的是解释与大小。
- `int a;` 本身不是错误；`printf("%d", a);`（赋值前）才是。
- 不要写死「int 一定是 4 字节」。
- `unsigned` 与 `signed` 混运算容易出怪结果（详见 c6）。
- 不要把负数当“干净”的 unsigned 哨兵。
- `014` 是八进制，不是十四。
- 不要用 `==` 直接比较浮点计算结果。
- 不要把 `'A'` 和 `"A"` 当成一样。
- `7 / 2` 写入 `double` 仍是 `3.0`，不是 `3.5`。
- 结果要留小数时，至少让 `/` 的一边是浮点类型。
- `i++` 与 `++i` 对变量最终都 +1，但表达式取出的值不同。
- 不要写 `i = i++ + ++i` 这类同一变量多重修改。
- `(double)(a / b)` 救不了整除；要在 `/` 之前出现浮点。
- 强制转换是临时视图，不会改写原变量里的值。
